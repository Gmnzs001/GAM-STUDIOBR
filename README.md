# GAM Studio

Site da GAM Studio — Next.js 16 (App Router) · React 19 · Tailwind v4.

```bash
npm install
npm run dev     # http://localhost:3000  (use /?intro=0 para pular a intro)
npm run build
```

- Conteúdo (contatos, serviços, cases, depoimentos): `lib/site.ts`
- Cases da página Portfólio: `app/portfolio/PortfolioGallery.tsx`
- Primitivos de UI: `components/system/` · tokens: `app/globals.css`
